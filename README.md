# Abu Ubaidah — Portfolio

My personal portfolio for showing IT support experience, systems work, software projects, certificates, and education.

## Built with

React, Vite, JavaScript, and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build for production

```bash
npm run build
npm run preview
```

Portfolio content is kept in `src/data/content.js`, while the section components and styling live in `src/components` and `src/index.css`.
